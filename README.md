# Дени Ислам

Браузерная игра от первого лица для Android, iPhone и компьютера. Все игроки, открывшие один адрес работающего сервера, встречаются в одной комнате.

## Запуск

Нужен Node.js 18 или новее:

```bash
npm install
npm start
```

Откройте адрес сервера на обоих устройствах. Для игры через интернет разместите приложение на общедоступном хостинге с поддержкой Node.js и WebSocket; статический хостинг не подойдёт. Сервер использует переменную окружения `PORT` (по умолчанию 3000). В одной Wi-Fi сети можно использовать локальный IP компьютера с сервером и порт 3000, если настройки сети и брандмауэра разрешают соединения.

На телефоне: левый палец — движение, правый — обзор. На компьютере: WASD или стрелки — движение, зажатая кнопка мыши — обзор. Частота кадров зависит от устройства и браузера; игра использует requestAnimationFrame и не ограничивает её искусственно, но 90 FPS гарантировать нельзя.

## Добавление на главный экран

После публикации сервера по HTTPS откройте один и тот же адрес игры на обоих телефонах. На iPhone откройте его в Safari, нажмите «Поделиться» → «На экран Домой». На Android можно открыть адрес в Chrome и выбрать «Добавить на главный экран» или «Установить приложение». Это веб-приложение, а не APK; подключение к серверу необходимо для игры. Временный предпросмотр не является постоянным адресом.

## Лифт и лабиринт

После падения есть 15 секунд на выбор: продолжить одному или подождать друга. Если выбор не сделан, лифт отправится одному; после выбора ожидания таймер больше не действует. Когда друг тоже упадёт, оба отправятся вместе. В лабиринте подойдите к табличке у лифта, чтобы прочитать правила. Молоток и гвоздодёр общие для игроков на сервере: гвоздодёром снимите четыре гвоздя, затем молотком — доски, после чего откройте дверь, чтобы попасть в пустую третью локацию. Прогресс сбрасывается, когда все игроки отключаются или сервер перезапускается. Двойное касание правой части экрана — прыжок; зажмите кнопку «Бег» для ускорения, пока хватает выносливости. На компьютере прыжок — пробел, бег — Shift.

## Монстр, инструменты и голос
Преследователь — загружаемая 3D-модель со скелетом (`public/models/michael.glb`). Ходьба и бег построены на вращении костей, поэтому меш не растягивается; мачете прикреплено к правой руке. Модель взята из папки Google Диска, которую прислал пользователь.


В лабиринте преследователь слышит движение поблизости, а бег и работа инструментом слышны дальше. Он перемещается по коридорам; зелёная область у лифта — безопасная зона. Если он поймает игрока, тот вернётся к лифту. Молоток и гвоздодёр появляются в случайных доступных местах при каждом новом прохождении: на полу, стене или потолке. Нажмите на найденный инструмент в нижнем инвентаре, чтобы взять его в руку; у двери сначала примените гвоздодёр, потом молоток. Совместное прохождение создаётся при спуске вместе; отдельный спуск создаёт новую независимую игру. При отключении всех участников состояние прохождения удаляется.

В настройках можно разрешить голосовой чат. Доступ к микрофону запрашивается только при включении; после разрешения микрофон по умолчанию заглушён, а кнопка в игре включает и выключает передачу. Оба игрока должны включить голос. Для него нужен HTTPS (или localhost), разрешение браузера и поддержка WebRTC. Используется STUN без TURN: некоторые мобильные сети или VPN могут не установить голосовое соединение. Записанные звуки и голос сервером не сохраняются.

Кнопка «История» показывает тип устройства и время последнего входа, замеченные текущим процессом сервера (тип определяется приблизительно по браузеру). История хранится только в памяти и исчезает при перезапуске сервера, в том числе при засыпании бесплатного хостинга.

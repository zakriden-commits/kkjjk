# Дени Ислам

Браузерная игра от первого лица для Android, iPhone и компьютера. Все игроки, открывшие один адрес работающего сервера, встречаются в одной комнате.

## Запуск

Нужен Node.js 18 или новее:

```bash
npm install
npm start
```

Откройте адрес сервера на обоих устройствах. Для игры через интернет разместите приложение на общедоступном хостинге с поддержкой Node.js и WebSocket; статический хостинг не подойдёт. Сервер использует переменную окружения `PORT` (по умолчанию 3000). В одной Wi-Fi сети можно использовать локальный IP компьютера с сервером и порт 3000, если настройки сети и брандмауэра разрешают соединения.

На телефоне: левый палец — движение, правый — обзор. На компьютере: WASD или стрелки — движение, зажатая кнопка мыши — обзор. Частота кадров зависит от устройства и браузера; игра использует requestAnimationFrame и не ограничивает её искусственно, но 90 FPS гарантировать нельзя.

## Добавление на главный экран

После публикации сервера по HTTPS откройте один и тот же адрес игры на обоих телефонах. На iPhone откройте его в Safari, нажмите «Поделиться» → «На экран Домой». На Android можно открыть адрес в Chrome и выбрать «Добавить на главный экран» или «Установить приложение». Это веб-приложение, а не APK; подключение к серверу необходимо для игры. Временный предпросмотр не является постоянным адресом.

## Лифт и лабиринт

После падения есть 15 секунд на выбор: продолжить одному или подождать друга. Если выбор не сделан, лифт отправится одному; после выбора ожидания таймер больше не действует. Когда друг тоже упадёт, оба отправятся вместе. В лабиринте подойдите к табличке у лифта, чтобы прочитать правила. Молоток и гвоздодёр общие для игроков на сервере: гвоздодёром снимите четыре гвоздя, затем молотком — доски, после чего откройте дверь и нажмите ещё раз, чтобы войти в тёмную комнату. Прогресс сбрасывается, когда все игроки отключаются или сервер перезапускается. Двойное касание правой части экрана — прыжок; зажмите кнопку «Бег» для ускорения, пока хватает выносливости. На компьютере прыжок — пробел, бег — Shift.
